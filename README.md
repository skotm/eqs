# EQS - Earthquake Simulator

**EQS** は、HTML5 Canvas と Web 標準技術で動作する、ブラウザベースの地震シミュレーターです。  
震源からの距離減衰、P波・S波の伝播、地盤増幅率（AVS30 / ARV）を考慮した震度推定をリアルタイムに可視化します。

## 特徴

- **地震波の可視化**
  - P波 / S波 / 表面波の伝播をアニメーション表示
  - 断層の向きによる指向性の表現
- **震度の推定**
  - 観測点ごとの震度を計算して表示
  - 地盤増幅率（AVS30 / ARV）を反映
- **表示モード**
  - 観測点ベースの表示
  - メッシュベースの地図表示
  - 緊急地震速報のシミュレーション表示
- **データ連携**
  - 過去の地震データを読み込み
  - 日本地図・震央地名・観測点データを利用
- **ブラウザ完結**
  - インストール不要
  - 静的ファイルだけで動作

## デモ

公開版: https://skotm.github.io/eqs/

## 画面イメージ

- 左上: 状態表示 / 時刻 / 警告表示
- 右上: モード表示
- 下部: 操作メニュー
- 中央: 地図と地震波の描画

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | アプリ本体 |
| `japan.geo.json` | 日本地図データ |
| `stations_with_amp_revised.json` | 観測点と地盤増幅率データ |
| `震央地名.geo.json` | 震央地名のポリゴンデータ |
| `jma_all_quakes.json` | 過去の地震履歴データ |

## 使い方

1. `index.html` をブラウザで開きます。
2. 地図上で地震の描画や再生を行います。
3. 設定パネルでマグニチュード、深さ、走向などを調整します。
4. 必要に応じて、履歴地震やプリセットを選択します。

## 操作

- **地図移動**: 左ドラッグ
- **ズーム**: マウスホイール
- **地震発生**: 地図上をクリック
- **設定変更**: 画面下部のメニューから各パラメータを調整

## 主な設定項目

- **Magnitude (Mj)**: 地震の規模
- **Depth (km)**: 震源の深さ
- **Speed**: 波の伝播速度倍率
- **Strike**: 断層の走向
- **Latest Quake / History / Presets**: 実データ・履歴・代表シナリオの切り替え

## 技術スタック

- HTML5
- CSS3
- JavaScript (ES2020+)
- Canvas API
- GeoJSON

## データソース

- **地震データ**: P2P地震情報
- **地図データ**: 国土地理院 / Global Map Japan を加工して利用
- **観測点・地盤データ**: NIED J-SHIS / 気象庁

## 注意事項

- 本アプリは学習・可視化用のシミュレーターです。
- 実際の地震被害や避難判断の根拠としては使用しないでください。
- 災害時は気象庁や自治体などの公式情報を確認してください。
